This is my first attempt at building a Web Audio synth with the help of AI.

2 oscillators with:

  wavetable (sine, triangle, square, etc)
  
  detune
  
  ADSR
  
  reverb
  
  delay
  
  filter
  
  vol
  
  pan
  
64 Step sequencer

MIDI input: Every slider/button can be mapped with "LEARN" function

Random OSC sound and random pattern sequencer buttons

How to use it?

Download HTML file and open with 

Windows: Chrome/Edge/Brave (tested)

Android: Chrome (tested)

OR
